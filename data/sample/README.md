# Sample data

**SYNTHETIC / MOCK DATA — NOT REAL CREDIT DATA — NOT FOR PRODUCTION USE**

`credit_sample.csv` is a tiny, hand-made synthetic dataset used only to
let Phase 0 stub code and tests run against something with the right
shape. It does not represent any real applicant, and its values are
not statistically meaningful.

The choice of a real vs. public dataset (e.g. UCI German Credit) for
Phase 1 real model training, and which column should serve as the
sensitive attribute for Arushi's fairness work, is still an open
decision for the team (see docs/TASK.md, section 14).
